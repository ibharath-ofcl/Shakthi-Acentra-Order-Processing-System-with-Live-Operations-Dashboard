# Project Documentation - Shakthi-Acentra System

## Overview
This directory stores architecture diagrams, system specifications, data models, API contracts, sequence diagrams, and operational runbooks for the Shakthi-Acentra Order Processing System.

## Planned Documentation Structure
- `architecture/`: High-level system topology, data flow diagrams, and event processing flows.
- `api/`: OpenAPI / Swagger specs, WebSocket event payload contracts, and error schemas.
- `database/`: Entity relationship diagrams (ERD) and migration documentation.
- `runbooks/`: Operational guidelines for queue management, failure recovery, and local environment troubleshooting.
